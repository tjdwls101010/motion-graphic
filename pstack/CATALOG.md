# 원본 영상 샷 카탈로그

`references/pstack/pstack.mp4`(24분 22초)에 나오는 모션그래픽 샷 중 이 레퍼런스가 다루는 3개 계열의 목록이다. 얼굴 캠만 나오는 구간과 실제 강연 영상은 뺐고, 디자인 레퍼런스로 다시 쓸 일이 없는 흰색 UI 카드·터미널 목업·얼굴 캠 위 오버레이·픽셀 범퍼 샷도 장면과 함께 뺐다. 시각은 4초 간격 프레임에서 읽은 것이라 ±4초 오차가 있고, 구현된 장면만 `ref`에 정확한 구간이 들어 있다.

- **계열**은 [STYLE.md](STYLE.md)의 3개 계열이다.
- **구현** 칸에 파일이 있으면 코드로 재구현된 샷이고, 비어 있으면 같은 계열의 키트로 이어서 만들 수 있는 후보다.
