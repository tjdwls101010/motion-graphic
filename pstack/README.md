# pstack

유튜브 영상 한 편(`references/pstack/pstack.mp4`, 24분)에 나오는 모션그래픽을 코드로 다시 만든 레퍼런스다.

- 장면 15개, 3개 계열. 원본에는 약 120개 샷이 있고, 디자인 레퍼런스로 다시 쓸 일이 없는 흰색 UI 카드·터미널 목업·얼굴 캠 위 오버레이·픽셀 범퍼 계열은 뺐다. 남은 계열의 샷 목록과 구현 여부는 [CATALOG.md](CATALOG.md), 계열별 룩과 모션 규칙은 [STYLE.md](STYLE.md)에 있다.
- 계열 이름과 시트에서의 순서는 [families.json](families.json)에 있다.

## 스타일 부품 (`kit/`)

장면은 공용 엔진(`../core/`) 위에 이 부품을 `<script src>`와 `<link>`로 불러 쓴다.

```
sketch.js   손그림 펜, 종이, 스틱맨, 로봇, 태그 (canvas)
felt.js/css 펠트 보드, 폴라로이드, 실, 이름표, 감자 (SVG)
set.js      책상, 휴대폰, 만년필, 걷는 인물, 버그
```

## 원본과 다른 점

- **출처:** 원본은 유튜브 채널 "김플립 - LLM 코딩"의 영상이다. 영상 파일과 거기서 뽑은 프레임은 저장소에 넣지 않았다(`.gitignore`). 모든 그림은 코드로 그린 것이다.
- **바꾼 것:** 자막, 진행자 웹캠, 실제 인물 사진, 브랜드 로고, 책 표지, 웹사이트 스크린샷은 재현하지 않고 중립적인 자리 표시(실루엣, 글자 하나짜리 배지, 뼈대 줄)로 대체했다. 화면 속 라벨 문구는 원본 그대로 두었다.
- **충실도:** `sketch`, `felt`, `set` 계열은 비트 순서와 구도는 맞지만 그림 세부(말·건물 같은 복잡한 사물, 펠트 질감)는 원본보다 단순하다. 장면마다 무엇을 단순화했는지는 대조 시트로 확인한다.
